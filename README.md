# System Log File Analyzer

Скрипт на Python для высокоэффективного потокового сканирования системных журналов Linux (syslog), автоматизированного поиска инцидентов по заданному маркеру и генерации локальных отчетов.


## 🛠️ Функционал

`log_analyzer.py` — выполняет "ленивое" построчное чтение лог-файла (0% RAM overhead) и контекстный поиск строк по заданному ключевому слову. Каждая найденная системная аномалия выводится в консоль терминала и одновременно дублируется в текстовый файл отчета в рабочей директории скрипта.

## 🚀 Инструкция по запуску
Скрипт автономно работает с абсолютными путями операционной системы и по умолчанию настроен на анализ живого журнала `/var/log/syslog`.

* **Production-окружение (боевой сервер):** Требуются права суперпользователя на чтение системных директорий.
* **Локальное тестирование:** Для проверки работоспособности на домашнем ПК достаточно подставить в переменную `TARGET_LOG` локальную копию файла (например, `access.log`).

```bash
# 1. Клонировать утилиту и перейти в каталог проекта
git clone https://github.com/Archibald-prog/syslog-analyzer.git
cd syslog-analyzer

# 2. Запуск потокового анализатора системного журнала
sudo python3 log_analyzer.py
```

## ⚙️ Системные требования
* **Операционная система:** Ubuntu / Debian / CentOS / RHEL
* **Интерпретатор:** Python v3.8+
* **Зависимости:** Только встроенные системные библиотеки (re, pathlib)
* **Права доступа:** root / sudo-привилегии (требуются для чтения /var/log/)
